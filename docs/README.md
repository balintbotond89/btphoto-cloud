## Azonosító-konvenció

- `BR-*` – Business Requirement
- `US-*` – User Story
- `FR-*` – Functional Requirement
- `AC-*` – Acceptance Criteria
- `NFR-*` – Non-functional Requirement
- `TR-*` – Technical Requirement
- `TC-*` – Test Case

Új funkció nem kerülhet implementálásra úgy, hogy nincs üzleti vagy technikai indoka és nincs meghatározott ellenőrzési módja.
